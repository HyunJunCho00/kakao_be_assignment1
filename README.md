# 📚 프로젝트 설명
이 프로젝트는 Enum, 제네릭, 람다 & 스트림을 활용하여 설계한 사칙연산 계산기 프로그램으로, 기능별로 클래스를 나누어 역할을 분담하고, 캡슐화를 지키면서 객체지향적으로 구현하였다.



## ✨ 프로젝트 주요 기능

### 1. OperatorType
- `enum`을 활용하여 사칙연산 기호(+, -, *, /)를 정의한다.

### 2. ArithmeticCalculator
- `제네릭 타입`을 사용하여 다양한 숫자 타입(`Integer`, `Double` 등)을 처리한다.
- `ArrayList`를 활용하여 연산 결과를 저장한다.
- 제공 기능:
  - 덧셈, 뺄셈, 곱셈, 나눗셈 연산을 수행한다.
  - 결과 목록을 조회한다.
  - 가장 오래된 결과를 삭제한다.
  - 특정 값보다 큰 결과 목록을 조회한다. (Lambda & Stream 사용)

### 3. App (main 함수)
- 사용자로부터 두 숫자와 연산 기호를 입력받는다.
- 숫자나 기호가 아닐 경우, 올바른 입력이 들어올 때까지 재입력을 요청한다.
- 연산을 수행한 후 결과를 출력하고, 저장된 결과 목록을 보여준다.

### 🛠 추가 기능
- `"yes"` 입력 시 가장 오래된 결과를 삭제하고 삭제 후 목록을 출력한다.
- `"yes"` 입력 시 특정 값보다 큰 결과를 조회할 수 있도록 숫자를 추가 입력받는다. (숫자가 아닐 경우 재입력을 요청한다)
- `"exit"` 입력 시 프로그램을 종료한다.
