# 📚 LV1 프로젝트 설명

기본적인 **사칙연산 기능**을 제공하는 콘솔 기반 계산기 프로그램이다.  
사용자로부터 두 정수와 연산 기호를 입력받아 계산을 수행하며, 잘못된 입력에 대해서는 **예외 처리를 통해 재입력을 유도**한다.  

## ✨ 프로젝트 주요 기능

### `Lv1_calculator` (Main 클래스)
- 사용자로부터 두 숫자와 연산 기호를 입력받는다.
- 숫자나 기호가 아닐 경우, 올바른 입력이 들어올 때까지 **재입력을 요청**한다.
- 나눗셈에서 0으로 나누는 경우 **`ArithmeticException` 예외 처리**를 통해 사용자에게 오류 메시지를 전달한다.
- 계산 결과를 출력한 후, 사용자에게 추가 계산 여부를 묻는다.
- `"exit"` 입력 시 프로그램을 종료한다.

# 📚 LV2 프로젝트 설명

LV2 프로젝트에서 간단한 **사칙연산 기능**을 수행하는 `Calculator_Lv2` 클래스를 분리하여 구현하고, 사용자 입력을 처리하는 `App_Lv2` 클래스를 통해 콘솔 기반 계산기 프로그램을 만들었다. 

## ✨ 프로젝트 주요 기능

### 1. `Calculator_Lv2` 
- 두 정수와 연산 기호를 받아 연산을 수행하는 `calculate(int x, int y, char oper)` 메서드 제공
- `List<Integer>` 컬렉션을 활용하여 **연산 결과를 저장**  
- `private` 접근 제어자를 사용해 캡슐화 적용, **외부에서 직접 결과 리스트 접근 불가**
- `getResult()` 및 `setResult()` 메서드를 통해 안전하게 결과 접근 가능
- 가장 오래된 결과를 삭제하는 `removeResult()` 메서드 제공

### 2. `App_Lv2` (Main 클래스)
- 사용자로부터 두 숫자와 연산 기호를 입력받는다.
- 숫자나 기호가 아닐 경우, 올바른 입력이 들어올 때까지 **재입력을 요청**한다.
- 연산을 수행한 후 결과를 출력하고, 저장된 결과 목록을 보여준다.
-  `"exit"` 입력 시 프로그램을 종료한다.

### 🛠 추가 기능
- `"yes"` 입력 시 가장 오래된 결과를 삭제하고 삭제 후 목록을 출력한다.

# 📚 LV3 프로젝트 설명
LV3는 LV1, LV2의 프로젝트와 동일하지만, Enum, 제네릭, 람다 & 스트림을 활용하여 설계한 사칙연산 계산기 프로그램으로, 기능별로 클래스를 나누어 역할을 분담하고, 캡슐화를 지키면서 객체지향적으로 구현하였다.

## ✨ 프로젝트 주요 기능

### 1. `OperatorType`
- `enum`을 활용하여 사칙연산 기호(+, -, *, /)를 정의

### 2. `ArithmeticCalculator`
- `제네릭 타입`을 사용하여 다양한 숫자 타입(`Integer`, `Double` 등)을 처리
- `ArrayList`를 활용하여 연산 결과를 저장
- 제공 기능:
  - 덧셈, 뺄셈, 곱셈, 나눗셈 연산을 수행
  - 결과 목록을 조회
  - 가장 오래된 결과를 삭제
  - 특정 값보다 큰 결과 목록을 조회 (Lambda & Stream 사용)

### 3.`App` (Main 클래스)
- 사용자로부터 두 숫자와 연산 기호를 입력받는다.
- 숫자나 기호가 아닐 경우, 올바른 입력이 들어올 때까지 **재입력을 요청**한다.
- 연산을 수행한 후 결과를 출력하고, 저장된 결과 목록을 보여준다.
- `"exit"` 입력 시 프로그램을 종료한다.


### 🛠 추가 기능
- `"yes"` 입력 시 가장 오래된 결과를 삭제하고 삭제 후 목록을 출력한다.
- `"yes"` 입력 시 특정 값보다 큰 결과를 조회할 수 있도록 숫자를 추가 입력받는다. (숫자가 아닐 경우 재입력을 요청한다)
